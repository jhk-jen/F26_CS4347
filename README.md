# Leaf & Brew (CS 4347 Team 4)

Online tea shop: customer storefront plus an admin dashboard.

## Phase 3 Task B: HTML/CSS interface

Static pages in `web/`; no database connection yet. Sample rows show where query results will go.

| File | Page |
|---|---|
| `web/index.html` | Shop / home: product grid with search, tea type, price and sort filters |
| `web/product.html` | Product page: details, add to cart, reviews, write-a-review form |
| `web/admin.html` | Admin dashboard: traffic chart, stock, recent orders, users |
| `web/css/style.css` | Shared styles |

Open `web/index.html` in a browser, or run `python3 -m http.server -d web 8765`.

Product photos in `web/img/` are placeholders cropped from the Phase 1 mockups.
